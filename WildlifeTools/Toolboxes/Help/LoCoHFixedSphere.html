Local Convex Hull (LoCoH) — Fixed Sphere

Jenness Enterprises Wildlife Tools · Home Range

Summary

Fixed-sphere-of-influence (r-) Local Convex Hull (LoCoH) home-range and utilization-distribution estimator (Getz et al. 2007). For every input point, the local hull is the convex hull of that focal point and all points within a sphere of influence of radius r, always including at least the focal point and its two nearest neighbors. Hulls are sorted by point count and merged cumulatively into density isopleths.

Usage

Choosing r: the radius r sets the size of each point's sphere of influence. Larger r gives larger, smoother hulls; smaller r gives tighter, more fragmented hulls. At least the focal point and its two nearest neighbors are always included, so every hull forms a polygon.

Getz et al. (2007) suggest, as a starting heuristic, r equal to half the maximum nearest-neighbor distance (the default option here, the r1 heuristic), then refining toward the value that minimizes combined Type I and Type II error via the “minimum spurious hole covering” (MSHC) rule (Getz and Wilmers 2004). The T-LoCoH package (Lyons, Turner and Getz 2013) recommends choosing the parameter empirically by examining how isopleth area and spurious holes change across a range of values.

When you specify a radius, it may be entered in any linear unit and is converted to meters internally. Screen out obvious location errors before running — LoCoH is sensitive to outliers.

Parameters

LabelExplanationData Type
Input point features The point features (for example, GPS or VHF telemetry fixes) from which the local hulls are built. May be in a geographic or projected coordinate system; empty or null geometries are ignored. Feature Layer
Sphere radius (r) Automatic (half the maximum nearest-neighbor distance) sets r to the Getz et al. 2007 r1 heuristic. Specify a radius enables the Radius parameter so you can enter a value. String
Radius The sphere radius r, used only when Specify a radius is chosen. Enter a value in any linear unit; it is converted to meters for the computation. The radius used is recorded in the output metadata. Linear Unit
Cumulative LoCoH [Fixed Sphere] Hulls Output polygon feature class of the dissolved cumulative LoCoH isopleths. Each feature stores its dissolved area (Area), enclosed point count (Point_Count), point proportion (Point_Proportion), the number of points within the sphere (Sphere_Point_Count), and point density in points per square kilometer (Pts_per_SqKm). Feature Class
Output individual hulls (optional) Optional output polygon feature class of the individual local convex hulls, each with its own area, the cumulative count and proportion at its rank, the within-sphere point count, and point density. Feature Class

Environments

This tool honors the following analysis environment:

  • Output Coordinate System — if set to a coordinate system other than the input's, the output polygons are reprojected to it as a last step. Areas, point counts, densities, and the within-sphere counts are still computed in the input coordinate system and are preserved unchanged.

No other geoprocessing environments affect this tool.

Code sample

LoCoHFixedSphere example (stand-alone script)

Run a fixed-sphere LoCoH using the automatic radius (half the maximum nearest-neighbor distance), creating the cumulative isopleths and the individual hulls.

import arcpy

arcpy.ImportToolbox(r"C:\Tools\JennessEnterprisesTools.pyt")

arcpy.jenness.LoCoHFixedSphere(
    "Owl_6_Points", "Automatic (half the maximum nearest-neighbor distance)", None,
    r"C:\Project\HomeRanges.gdb\Owl_6_Points_FixedSphere_Cumulative",
    r"C:\Project\HomeRanges.gdb\Owl_6_Points_FixedSphere_Hulls")
