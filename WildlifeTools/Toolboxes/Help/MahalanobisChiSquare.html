Mahalanobis Distance — Chi-Square Transform

Jenness Enterprises Wildlife Tools · Mahalanobis Tools

Summary

Transforms a Mahalanobis squared-distance (D²) raster into a chi-square typicality p-value raster, rescaling the unbounded D² values onto a fixed 0–1 scale where values near 1 indicate a close match to the reference conditions.

Usage

For every cell the output is the upper-tail chi-square probability p = P(χ² > D²), evaluated with degrees of freedom equal to the number of variables that produced the D² raster. Mahalanobis distances have no upper bound; this transform recodes them onto a fixed 0–1 scale.

Because the transform is monotonic it also inverts the order: high D² (dissimilar) becomes a low p-value, and low D² (similar) becomes a high p-value. The computation is performed cell-by-cell (block vectorized), so it stays memory-bounded for large rasters; NoData cells remain NoData.

The input must be a squared-distance (D²) raster — not a Distance (D) or an already-transformed p-value raster. When the D² raster was created by the Mahalanobis Distance — Create Raster Surface tool, its number of variables (the degrees of freedom) is recorded in the raster metadata and pre-filled here automatically; a warning is shown if the input metadata indicates it is not a D² raster.

Parameters

LabelExplanationData Type
Input squared-distance (D²) raster The Mahalanobis D² raster to rescale. If it was produced by the Mahalanobis Raster tool, its variable count is read from the metadata to pre-fill the degrees of freedom, and a warning appears if the metadata shows the raster is not a D² surface. Raster Layer
Degrees of freedom (number of variables) The chi-square degrees of freedom, equal to the number of variables used to build the D² raster. Pre-filled automatically when the input metadata records it; otherwise enter the number of variables. Long
Output chi-square p-value raster The output p-value raster (0–1, values near 1 indicating a close match). Defaults to Mahalanobis_Pvalue, auto-incremented if taken. Raster Dataset

Environments

This tool reads the input raster on its own grid and does not depend on the analysis environments. The output matches the input raster's coordinate system, cell size, and extent.

Code sample

MahalanobisChiSquare example (stand-alone script)

Rescale a three-variable Mahalanobis D² raster to a chi-square typicality p-value (df = 3).

import arcpy

arcpy.ImportToolbox(r"C:\Tools\JennessEnterprisesTools.pyt")

arcpy.jenness.MahalanobisChiSquare(
    in_raster=r"C:\Project\Mahalanobis.gdb\Mahalanobis",
    df=3,
    out_raster=r"C:\Project\Mahalanobis.gdb\Mahalanobis_Pvalue")

References and further reading

Method:

  • Mahalanobis, P.C. (1936). On the generalised distance in statistics. Proceedings of the National Institute of Sciences of India 2(1):49–55.

Chi-square rescaling in ecological applications (and its normality assumption):

  • Clark, J.D., Dunn, J.E. and Smith, K.G. (1993). A multivariate model of female black bear habitat use for a geographic information system. Journal of Wildlife Management 57:519–526.
  • Knick, S.T. and Dyer, D.L. (1997). Distribution of black-tailed jackrabbit habitat determined by GIS in southwestern Idaho. Journal of Wildlife Management 61:75–85.
  • Farber, O. and Kadmon, R. (2002). Assessment of alternative approaches for bioclimatic modeling with special emphasis on the Mahalanobis distance. Ecological Modelling 160:115–130.
Degrees of freedom: this tool uses df = the number of variables, the statistically standard value (Mardia, Kent and Bibby 1979; Seber 1984). Some of the ecological sources above use the number of variables − 1 (Clark et al. 1993; Farber and Kadmon 2003). Because the transform is monotonic in D², this choice only rescales the p-values — it never changes the ranking of cells. Set the degrees of freedom yourself to reproduce those sources.
