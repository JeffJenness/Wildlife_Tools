Mahalanobis Distance — Calculate at Points

Jenness Enterprises Wildlife Tools · Mahalanobis Tools

Summary

Calculates a Mahalanobis value at each input point, measuring how far the point's combination of landscape-variable values lies from a multivariate reference mean, scaled by the inverse covariance among the variables.

Usage

The value for a point is the quadratic form D² = (x − μ)' · Σ⁻¹ · (x − μ), where x is the point's vector of landscape-variable values, μ is the mean vector, and Σ⁻¹ is the inverse covariance matrix. The reference mean and covariance can be computed from a point sample, from the cells of a categorical raster, or read from previously saved tables.

The output is a copy of the input points with one added field (Mahal_D2, Mahal_D, or Mahal_pval depending on the output value). Points that fall outside the extent of any landscape raster, or on a NoData cell, receive a null value.

Predictor rasters always contribute their cell values, never raster attribute-table values. A multiband raster expands to one variable per band. A predictor may instead be a polygon feature layer plus a numeric field.

A common workflow is to leave Sample points for statistics empty so the mean and covariance are built from the input points themselves — each point's value is then its Mahalanobis distance from the centroid of all the points, useful for flagging atypical observations. Provide a separate statistics sample (or existing tables) to evaluate the points against a different reference distribution.

Reference: Mahalanobis, P.C. (1936). On the generalised distance in statistics. Proceedings of the National Institute of Sciences of India 2(1):49–55.

Environments

This tool honors the following analysis environments, which define the grid on which the landscape variables are sampled at the points:

  • Output Coordinate System
  • Cell Size
  • Processing Extent — points outside it receive a null value.
  • Snap Raster

Other geoprocessing environments do not affect this tool.

Code sample

MahalanobisPoints example (stand-alone script)

Compute a squared-distance (D²) Mahalanobis value at each observed location, building the mean and covariance from those same points.

import arcpy

arcpy.ImportToolbox(r"C:\Tools\JennessEnterprisesTools.pyt")

arcpy.jenness.MahalanobisPoints(
    target_points="Observed_Locations",
    raster_vars="elev_clip;slope_clip;curvature",
    sample_method="Interpolated (bilinear)",
    stats_source="Calculate directly from sample point features",
    inversion="Standard (inverse)",
    out_points=r"C:\Project\Mahalanobis.gdb\Observed_Mahal",
    out_type="Squared distance (D2): Traditional for ecological modeling")

MahalanobisPoints example 2 (evaluate against existing tables)

Score a separate set of candidate points against a mean and covariance saved earlier, returning a chi-square typicality p-value.

import arcpy

arcpy.ImportToolbox(r"C:\Tools\JennessEnterprisesTools.pyt")

gdb = r"C:\Project\Mahalanobis.gdb"
arcpy.jenness.MahalanobisPoints(
    target_points="Candidate_Sites",
    raster_vars="elev_clip;slope_clip;curvature",
    sample_method="Exact (nearest cell)",
    stats_source="Existing tables",
    mean_table=gdb + r"\Observed_Mahal_Means",
    cov_table=gdb + r"\Observed_Mahal_Covariance",
    inversion="Standard (inverse)",
    out_points=gdb + r"\Candidate_typicality",
    out_type="Chi-square p-value")
