Mahalanobis Distance — Calculate at Points

Jenness Enterprises Wildlife Tools · Mahalanobis Tools

Summary

Calculates a Mahalanobis value at each input point, measuring how far the point's combination of landscape-variable values lies from a multivariate reference mean, scaled by the inverse covariance among the variables.

Usage

The value for a point is the quadratic form D² = (x − μ)' · Σ⁻¹ · (x − μ), where x is the point's vector of landscape-variable values, μ is the mean vector, and Σ⁻¹ is the inverse covariance matrix. The reference mean and covariance can be computed from a point sample, or read from previously saved tables.

The output is a copy of the input points with one added field per selected output value (Mahal_D2, Mahal_D, and/or Mahal_pval) — you may calculate any or all of the three. Points that fall outside the extent of any landscape raster, or on a NoData cell, receive a null value.

Predictor rasters always contribute their cell values, never raster attribute-table values. A multiband raster expands to one variable per band. A predictor may instead be a polygon feature layer plus a numeric field.

A common workflow is to leave Sample points for statistics empty so the mean and covariance are built from the input points themselves — each point's value is then its Mahalanobis distance from the centroid of all the points, useful for flagging atypical observations. Provide a separate statistics sample (or existing tables) to evaluate the points against a different reference distribution.

Environments

This tool honors the following analysis environments, which define the grid on which the landscape variables are sampled at the points:

  • Output Coordinate System
  • Cell Size
  • Processing Extent — points outside it receive a null value.
  • Snap Raster

Other geoprocessing environments do not affect this tool.

Code sample

MahalanobisPoints example (stand-alone script)

Compute a squared-distance (D²) Mahalanobis value at each observed location, building the mean and covariance from those same points.

import arcpy

arcpy.ImportToolbox(r"C:\Tools\JennessEnterprisesTools.pyt")

arcpy.jenness.MahalanobisPoints(
    target_points="Observed_Locations",
    raster_vars="elev_clip;slope_clip;curvature",
    sample_method="Interpolated (bilinear)",
    stats_source="Calculate directly from sample point features",
    inversion="Standard (inverse)",
    out_points=r"C:\Project\Mahalanobis.gdb\Observed_Mahal",
    out_d2=True,
    out_d=False,
    out_pval=True)

MahalanobisPoints example 2 (evaluate against existing tables)

Score a separate set of candidate points against a mean and covariance saved earlier, returning a chi-square typicality p-value.

import arcpy

arcpy.ImportToolbox(r"C:\Tools\JennessEnterprisesTools.pyt")

gdb = r"C:\Project\Mahalanobis.gdb"
arcpy.jenness.MahalanobisPoints(
    target_points="Candidate_Sites",
    raster_vars="elev_clip;slope_clip;curvature",
    sample_method="Exact (nearest cell)",
    stats_source="Existing tables",
    mean_table=gdb + r"\Observed_Mahal_Means",
    cov_table=gdb + r"\Observed_Mahal_Covariance",
    inversion="Standard (inverse)",
    out_points=gdb + r"\Candidate_typicality",
    out_d2=False,
    out_d=False,
    out_pval=True)

References and further reading

Method:

  • Mahalanobis, P.C. (1936). On the generalised distance in statistics. Proceedings of the National Institute of Sciences of India 2(1):49–55.

Ecological applications (including the chi-square rescaling and its normality caveat):

  • Clark, J.D., Dunn, J.E. and Smith, K.G. (1993). A multivariate model of female black bear habitat use for a geographic information system. Journal of Wildlife Management 57:519–526.
  • Knick, S.T. and Dyer, D.L. (1997). Distribution of black-tailed jackrabbit habitat determined by GIS in southwestern Idaho. Journal of Wildlife Management 61:75–85.
  • Farber, O. and Kadmon, R. (2002). Assessment of alternative approaches for bioclimatic modeling with special emphasis on the Mahalanobis distance. Ecological Modelling 160:115–130.

Matrix algebra and computation:

  • Golub, G.H. and Van Loan, C.F. (1996). Matrix Computations, 3rd ed. Johns Hopkins University Press.
  • Meyer, C.D. (2000). Matrix Analysis and Applied Linear Algebra. SIAM, Philadelphia.
  • Press, W.H., Teukolsky, S.A., Vetterling, W.T. and Flannery, B.P. (2002). Numerical Recipes in C: The Art of Scientific Computing, 2nd ed. Cambridge University Press.
Degrees of freedom: the chi-square p-value uses df = the number of variables, the statistically standard value (Mardia, Kent and Bibby 1979; Seber 1984). Some of the ecological sources above use the number of variables − 1 (Clark et al. 1993; Farber and Kadmon 2003). Because the transform is monotonic in D², this choice only rescales the p-values — it never changes the ranking of points.
