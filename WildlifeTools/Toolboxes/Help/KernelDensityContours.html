Kernel Density Probability Contours

Jenness Enterprises Wildlife Tools · Kernel Density Tools

Summary

Generates home-range probability (volume) isopleths from a kernel-density surface at the standard levels (5 percent to 100 percent in 5 percent steps), as contour polylines and/or polygon areas.

Usage

A probability isopleth is a contour that encloses a given percentage of the total volume under a kernel density surface: the X percent isopleth bounds the smallest area containing X percent of the estimated use — the standard way to delineate kernel home ranges (for example, the 95 percent and 50 percent contours).

The tool automatically recognizes what kind of raster you supply:

  • A kernel density raster (the Esri Kernel Density output, or the Densities or Expected counts output of Kernel Density Enhanced): the tool sorts the cell values, accumulates the volume, and finds the density threshold that encloses each target percentage, then contours those thresholds.
  • A proportion-under-the-surface raster (from the Kernel Density to Proportion Surface tool, or the Proportion output of Kernel Density Enhanced): the cumulative volume is already stored in the cells, so the tool simply contours the standard proportion levels directly. Such rasters are identified by a marker written into their metadata.

You may produce contour polylines, polygon areas, or both; at least one is required. The polygon boundaries coincide exactly with the polylines. Both outputs carry the same attribute fields (see Output fields, below).

This tool honors the Output Coordinate System environment: contours are generated in the raster's own coordinate system, and the finished outputs are reprojected if an Output Coordinate System is set. No other environments affect it.

Output fields

The polyline and polygon outputs both contain these attribute fields (each field also carries this definition in its metadata, with source “Jenness Enterprises”):

FieldDefinition
Density The raster value contoured to produce this isopleth — the kernel-density threshold for a kernel-density input, or the cumulative proportion for a proportion-under-the-surface input.
Isopleth The home-range isopleth level: the proportion (0 to 1) of the total volume under the surface enclosed by this contour (for example, 0.95 is the 95 percent isopleth).
CumProportion The cumulative proportion of volume outside this isopleth (1 minus Isopleth); equivalently, the value at which to contour a proportion-under-the-surface raster to reproduce this isopleth.
Label The isopleth level as a percentage label (for example, “95%”).
Primary Whether this is a primary (more prominent) isopleth. A coded-value field:
  • True — a primary isopleth (the 5, 25, 50, 75, and 95 percent levels).
  • False — a secondary (minor) isopleth.

Code sample

KernelDensityContours example (stand-alone script)

Generate probability isopleth polylines and polygon areas from a kernel density raster.

import arcpy

arcpy.ImportToolbox(r"C:\Tools\JennessEnterprisesTools.pyt")

arcpy.jenness.KernelDensityContours(
    in_raster=r"C:\Project\HomeRange.gdb\KD_density",
    make_lines=True,
    out_lines=r"C:\Project\HomeRange.gdb\KD_isopleth_lines",
    make_polys=True,
    out_polys=r"C:\Project\HomeRange.gdb\KD_isopleth_areas")
