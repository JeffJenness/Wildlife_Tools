Local Convex Hull (LoCoH) — Adaptive

Jenness Enterprises Wildlife Tools · Home Range

Summary

Adaptive (a-) Local Convex Hull (LoCoH) home-range and utilization-distribution estimator (Getz et al. 2007). For every input point, neighbors are added in order of increasing distance until their cumulative distance reaches the maximum cumulative length a; the convex hull of the focal point and its selected neighbors becomes its local hull. Hulls are sorted by point count and merged cumulatively into density isopleths.

Usage

Choosing a: the maximum cumulative length a controls how far the cumulative neighbor distance may extend before a local hull is closed. Larger a gives larger, smoother hulls; smaller a gives tighter, more fragmented hulls (too small, and many focal points have fewer than 3 neighbors and are skipped).

Getz et al. (2007) suggest, as a starting heuristic, a equal to the maximum distance between any pair of points (the default option here), then refining downward toward the value that minimizes combined Type I and Type II error via the “minimum spurious hole covering” (MSHC) rule (Getz and Wilmers 2004). The T-LoCoH package (Lyons, Turner and Getz 2013) recommends choosing the parameter empirically by examining how isopleth area and spurious holes change across a range of values.

When you specify a length, it may be entered in any linear unit and is converted to meters internally; the adaptive cumulative distance is reported in the unit you chose. Screen out obvious location errors before running — LoCoH is sensitive to outliers.

Parameters

LabelExplanationData Type
Input point features The point features (for example, GPS or VHF telemetry fixes) from which the local hulls are built. May be in a geographic or projected coordinate system; empty or null geometries are ignored. Feature Layer
Maximum cumulative length (a) Maximum distance between any pair of points sets a automatically (the Getz et al. 2007 heuristic). Specify a length enables the Length parameter so you can enter a value. String
Length The maximum cumulative length a, used only when Specify a length is chosen. Enter a value in any linear unit; it is converted to meters for the computation, and the adaptive cumulative distance is reported in the unit you choose. Linear Unit
Cumulative LoCoH [Adaptive] Hulls Output polygon feature class of the dissolved cumulative LoCoH isopleths. Each feature stores its dissolved area (Area), enclosed point count (Point_Count), point proportion (Point_Proportion), and the adaptive cumulative distance (Adaptive_Cumulative_Dist). Feature Class
Output individual hulls (optional) Optional output polygon feature class of the individual local convex hulls, each with its own area and the cumulative count, proportion, and adaptive distance at its rank. Feature Class

Environments

This tool honors the following analysis environment:

  • Output Coordinate System — if set to a coordinate system other than the input's, the output polygons are reprojected to it as a last step. Areas, point counts, densities, and the adaptive distance are still computed in the input coordinate system and are preserved unchanged.

No other geoprocessing environments affect this tool.

Code sample

LoCoHAdaptive example (stand-alone script)

Run an adaptive LoCoH using the maximum distance between any pair of points, creating the cumulative isopleths and the individual hulls.

import arcpy

arcpy.ImportToolbox(r"C:\Tools\JennessEnterprisesTools.pyt")

arcpy.jenness.LoCoHAdaptive(
    "Owl_6_Points", "Maximum distance between any pair of points", None,
    r"C:\Project\HomeRanges.gdb\Owl_6_Points_Adaptive_Cumulative",
    r"C:\Project\HomeRanges.gdb\Owl_6_Points_Adaptive_Hulls")
