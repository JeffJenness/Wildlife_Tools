Local Convex Hull (LoCoH) — Standard

Jenness Enterprises Wildlife Tools · Home Range

Summary

Standard (fixed-k) Local Convex Hull (LoCoH) home-range and utilization-distribution estimator (Getz and Wilmers 2004). For every input point, the tool builds the convex hull of that point plus its k−1 nearest neighbors, sorts the hulls by area, and merges them cumulatively into density isopleths.

Usage

Choosing k: small k produces tighter, more fragmented hulls that capture fine structure and hard boundaries (rivers, cliffs, habitat edges), while large k produces smoother, more contiguous ranges; k equal to the number of points reduces to the minimum convex polygon. k must be at least 3 and no greater than the number of points.

Getz and Wilmers (2004) recommend the “minimum spurious hole covering” (MSHC) rule: select the smallest k that fills spurious holes so the covering attains the correct topology. As a heuristic starting value, Getz et al. (2007) suggest k = √n, then refine toward the value that minimizes combined Type I and Type II error. The T-LoCoH package (Lyons, Turner and Getz 2013) recommends choosing the parameter empirically by examining how isopleth area and spurious holes change across a range of values.

Screen out obvious location errors before running — LoCoH is sensitive to outliers. Distances and areas honor the input coordinate system: Haversine distance and WGS84 spheroidal area for geographic data, planar distance and area for projected data.

Parameters

LabelExplanationData Type
Input point features The point features (for example, GPS or VHF telemetry fixes) from which the local hulls are built. May be in a geographic or projected coordinate system; empty or null geometries are ignored. Feature Layer
Number of nearest neighbors (k) The number of nearest neighbors used to build each local convex hull, including the focal point itself, so each hull is formed from a point and its k−1 nearest neighbors. Must be at least 3 and no greater than the number of input points. Long
Cumulative LoCoH [Standard] Hulls Output polygon feature class of the dissolved cumulative LoCoH isopleths. Each feature stores its dissolved area (Area), the number of enclosed points (Point_Count), and the point proportion (Point_Proportion). Feature Class
Output individual hulls (optional) Optional output polygon feature class of the individual local convex hulls, each storing its own area and the cumulative point count and proportion at its position in the area-sorted sequence. Feature Class

Environments

This tool honors the following analysis environment:

  • Output Coordinate System — if set to a coordinate system other than the input's, the output polygons are reprojected to it as a last step. Areas, point counts, and densities are still computed in the input coordinate system (Haversine/spheroidal for geographic data, planar for projected data) and are preserved unchanged.

No other geoprocessing environments affect this tool.

Code sample

LoCoHStandard example (stand-alone script)

Run a 10-neighbor Standard LoCoH on a point layer, creating the cumulative isopleths and the individual hulls.

import arcpy

arcpy.ImportToolbox(r"C:\Tools\JennessEnterprisesTools.pyt")

arcpy.jenness.LoCoHStandard(
    "Owl_6_Points", 10,
    r"C:\Project\HomeRanges.gdb\Owl_6_Points_Cumulative_10k",
    r"C:\Project\HomeRanges.gdb\Owl_6_Points_Hulls_10k")
