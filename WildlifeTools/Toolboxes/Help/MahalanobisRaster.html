Mahalanobis Distance — Create Raster Surface

Jenness Enterprises Wildlife Tools · Mahalanobis Tools

Summary

Creates a raster of Mahalanobis distances measuring, for every cell, how far that cell's combination of landscape-variable values lies from a multivariate reference mean, scaled by the inverse covariance among the variables.

Usage

The squared Mahalanobis distance for a cell is the quadratic form D² = (x − μ)' · Σ⁻¹ · (x − μ), where x is the cell's vector of landscape-variable values, μ is the mean vector, and Σ⁻¹ is the inverse covariance matrix. The reference mean and covariance can be computed from sample point features, from the cells of a categorical raster, or read from previously saved tables.

The computation is performed cell-by-cell (block vectorized) rather than through whole-raster map algebra, so it stays memory-bounded for large rasters and many variables.

Predictor rasters always contribute their cell values, never any raster attribute-table values. Rasters are added to the Raster Landscape Variables list; polygon variables (a polygon feature class plus a numeric field, rasterized to the grid) go in the separate Polygon Landscape Variables table, which has a validated field dropdown.

A multiband raster is expanded automatically to one variable per band, named raster_Band_X. To leave out specific bands, add them to the Bands to exclude table (name the multiband raster and the band number).

Output value choices are all functions of the same per-cell D²: Squared distance (D²) is the traditional ecological-modeling quantity and the input required by a chi-square transform; Distance (D) is its square root; Chi-square p-value is the upper-tail typicality probability (0–1, with values near 1 indicating a close match to the reference conditions).

Environments

This tool honors the following analysis environments:

  • Output Coordinate System — the analysis-grid coordinate system; predictors are reprojected to it.
  • Cell Size — the analysis-grid resolution.
  • Processing Extent — clips the analysis grid (intersected with the predictor data, snapped to cells).
  • Snap Raster — aligns the analysis-grid origin to the snap raster's cells.
  • Mask — cells outside the mask are written as NoData.

Other geoprocessing environments do not affect this tool.

Code sample

MahalanobisRaster example (stand-alone script)

This example calculates a Mahalanobis squared-distance (D²) raster from three rasters currently available in the active map — elev_clip, slope_clip, and curvature — with the mean vector and covariance matrix calculated from a point layer named Sample_Points_for_Mahal, also in the current map. It also saves the four statistics tables.

import arcpy

arcpy.ImportToolbox(r"C:\Tools\JennessEnterprisesTools.pyt")

out_gdb = r"C:\Project\Mahalanobis.gdb"
arcpy.jenness.MahalanobisRaster(
    raster_vars="elev_clip;slope_clip;curvature",
    sample_method="Interpolated (bilinear)",
    stats_source="Calculate directly from sample point features",
    points="Sample_Points_for_Mahal",
    use_selected=False,
    inversion="Standard (inverse)",
    out_raster=out_gdb + r"\Mahalanobis",
    out_type="Squared distance (D2): Traditional for ecological modeling",
    gen_mean=True,  save_mean=out_gdb + r"\Mahalanobis_Means",
    gen_cov=True,   save_cov=out_gdb + r"\Mahalanobis_Covariance",
    gen_invcov=True, save_invcov=out_gdb + r"\Mahalanobis_Inv_Covariance",
    gen_corr=True,  save_corr=out_gdb + r"\Mahalanobis_Correlation")

MahalanobisRaster example 2 (reuse saved statistics, with environments)

Apply a previously saved mean vector and covariance matrix to a multiband image, clipping the result to a study-area mask and a 30-meter grid.

import arcpy

arcpy.ImportToolbox(r"C:\Tools\JennessEnterprisesTools.pyt")

# Multiband_Input expands to one variable per band automatically.
arcpy.env.cellSize = 30
arcpy.env.mask = r"C:\Project\StudyArea.gdb\boundary"

arcpy.jenness.MahalanobisRaster(
    raster_vars="Multiband_Input",
    sample_method="Exact (nearest cell)",
    stats_source="Existing tables",
    mean_table=r"C:\Project\Mahalanobis.gdb\Mahalanobis_Means",
    cov_table=r"C:\Project\Mahalanobis.gdb\Mahalanobis_Covariance",
    inversion="Pseudo-inverse (SVD)",
    out_raster=r"C:\Project\Mahalanobis.gdb\Mahal_typicality",
    out_type="Chi-square p-value")

References and further reading

Method:

  • Mahalanobis, P.C. (1936). On the generalised distance in statistics. Proceedings of the National Institute of Sciences of India 2(1):49–55.

Ecological applications (including the chi-square rescaling and its normality caveat):

  • Clark, J.D., Dunn, J.E. and Smith, K.G. (1993). A multivariate model of female black bear habitat use for a geographic information system. Journal of Wildlife Management 57:519–526.
  • Knick, S.T. and Dyer, D.L. (1997). Distribution of black-tailed jackrabbit habitat determined by GIS in southwestern Idaho. Journal of Wildlife Management 61:75–85.
  • Farber, O. and Kadmon, R. (2002). Assessment of alternative approaches for bioclimatic modeling with special emphasis on the Mahalanobis distance. Ecological Modelling 160:115–130.

Matrix algebra and computation:

  • Golub, G.H. and Van Loan, C.F. (1996). Matrix Computations, 3rd ed. Johns Hopkins University Press.
  • Meyer, C.D. (2000). Matrix Analysis and Applied Linear Algebra. SIAM, Philadelphia.
  • Press, W.H., Teukolsky, S.A., Vetterling, W.T. and Flannery, B.P. (2002). Numerical Recipes in C: The Art of Scientific Computing, 2nd ed. Cambridge University Press.
Degrees of freedom: the chi-square p-value uses df = the number of variables, the statistically standard value (Mardia, Kent and Bibby 1979; Seber 1984). Some of the ecological sources above use the number of variables − 1 (Clark et al. 1993; Farber and Kadmon 2003). Because the transform is monotonic in D², this choice only rescales the p-values — it never changes the ranking of cells.
