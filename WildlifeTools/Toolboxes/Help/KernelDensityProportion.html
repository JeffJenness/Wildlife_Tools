Kernel Density to Proportion Surface

Jenness Enterprises Wildlife Tools · Kernel Density Tools

Summary

Converts a kernel-density raster into a proportion-under-the-surface (volume) raster, where each cell holds the cumulative proportion of the total volume under the surface — from about 0 at the outer edge to 1 at the peak.

Usage

The “volume” under a kernel density surface is the sum of all cell values (the cell area is constant, so it cancels out of every proportion). For each cell, this tool reports the share of that total volume contributed by all cells whose density is less than or equal to the cell's own density. The result runs from about 0 at the outermost (lowest-density) boundary up to 1.0 at the peak — oriented like the raw kernel density, but rescaled to the range 0 to 1.

The proportion surface is designed to be contoured. To draw the X percent home-range isopleth, contour the surface at the value (1 − X/100): for example, contour at 0.05 for the 95 percent isopleth, or at 0.50 for the 50 percent isopleth. The Kernel Density Probability Contours tool recognizes a proportion surface automatically (by a marker written into its metadata) and contours the standard isopleth levels for you.

The output raster has a single continuous value band (no attribute table) and carries statistics and a histogram so it renders correctly without a separate Calculate Statistics step. Zero and NoData cells of the input are excluded from the volume. The output remains in the same coordinate system as the source raster; the tool transforms the input grid cell-for-cell and does not honor the Output Coordinate System or other analysis environments.

Parameters

LabelExplanationData Type
Input kernel density raster A kernel density (or any positive intensity) raster. Cell values are treated as density; zero and NoData cells are excluded. Raster Layer
Output proportion raster The output proportion-under-the-surface raster (values 0 to 1), in the same coordinate system as the input. Raster Dataset

Environments

This tool does not honor analysis environments: the output mirrors the input raster's grid and coordinate system cell-for-cell.

Code sample

KernelDensityProportion example (stand-alone script)

Convert a kernel density raster to a proportion surface, then contour it at 0.05 for the 95 percent home-range isopleth.

import arcpy

arcpy.ImportToolbox(r"C:\Tools\JennessEnterprisesTools.pyt")

arcpy.jenness.KernelDensityProportion(
    in_raster=r"C:\Project\HomeRange.gdb\KD_density",
    out_raster=r"C:\Project\HomeRange.gdb\KD_proportion")
